# FlappyMung

**2인 실시간 대전 플래피버드 · Google Play 출시작**
**2人リアルタイム対戦フラッピーバード・Google Playリリース作品**

<!-- 스크린샷이나 플레이 GIF가 있으면 여기에 넣으세요: ![play](docs/play.gif) -->

## 개요 · 概要

두 명이 같은 방에 들어가 동시에 플래피버드를 플레이하는 멀티플레이 모바일 게임입니다.
계정 관리부터 멀티플레이, 스토어 출시까지 혼자 진행한 첫 프로젝트입니다.

2人が同じルームに入り、同時にフラッピーバードをプレイするマルチプレイモバイルゲームです。
アカウント管理からマルチプレイ、ストアリリースまで一人で行った初めてのプロジェクトです。

- 개발 / 開発: 1인 / 個人
- 플랫폼 / プラットフォーム: Android (Google Play) <!-- 스토어 링크가 아직 살아 있으면: [Google Play](링크) -->
- 엔진·언어 / エンジン・言語: Unity · C#

## 주요 기능 · 主な機能

- **계정 관리 / アカウント管理** — Firebase Authentication으로 로그인·계정 관리
- **방 생성·매칭 / ルーム作成・マッチング** — Photon PUN2로 방장이 방을 만들고, 다른 플레이어 1명을 찾아 입장
- **실시간 2인 플레이 / リアルタイム2人プレイ** — 방장 클라이언트(Master Client)를 기준으로 두 플레이어가 동시에 플레이
- **스토어 출시 / ストアリリース** — 빌드 서명부터 Google Play 등록까지 직접 진행
